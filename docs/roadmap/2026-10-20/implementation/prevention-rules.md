# Reglas preventivas de las regresiones reproducidas

- Una CheckedContinuation tiene un único dueño: retirarla del estado antes de resume. La cancelación debe resolver la espera; una devolución tardía debe validar la identidad de ejecución dentro del actor antes de tocar estado. Prueba: workflow-confirmations-before.log, cuatro escenarios fallidos, incluidos dos SIGTRAP; workflow-confirmations-after.log, seis escenarios pasan.
- Cada pregunta requiere además su propio identificador: consumir una continuación no impide que un segundo evento UI tardío acepte la siguiente espera. La API debe exigir el ID capturado al mostrar la pregunta. workflow-stale-decision-before.log reproduce el fallo y workflow-decisions-after.log comprueba siete escenarios.
- Los fixtures deben aislar Git tanto al construir el repositorio como al lanzar la aplicación. Preparar un repo temporal no evita que la app lea/escriba configuración global. SnapshotHelper.launchEnvironment y test-ui-test-foundation comprueban ambos límites.
- Activar y verificar el proceso privado antes de capturar; verificar el mismo PID después. No relanzar automáticamente una app caída ni presentar capturas de otra aplicación como defectos de GitMac. Las capturas anteriores contaminadas permanecen como evidencia inválida.
- Comparar píxeles después de convertir el perfil ICC a sRGB. Los bytes RGB sin conversión y NSBitmapImageRep no probaron el mismo contrato en estas capturas de monitor. El test UI usa CGContext sRGB y los inspectores de PNG usan ImageCms.
- Una política de color correcta en DSButton no demuestra que sus consumidores la respeten: un foregroundStyle dentro de la etiqueta puede anularla. Revisar originales y probar el consumidor. account-contrast-before.log detecta el problema en ocho presets.
- Conservar hashes del código y del ejecutable de cada captura. Un resultado de un candidato anterior no aprueba automáticamente el binario reconstruido. Las hojas de contacto conservan origen/hash y declaran su pérdida de detalle.
- Ante un pico gráfico, registrar geometría antes de modificar tamaños por intuición. El observador de startup-window-memory.log vio 900×450 puntos; no respalda la hipótesis de ventana enorme. Conservar el fallo de presupuesto y distinguir una categoría de memoria de su causa.

- Un lector de píxeles debe declarar su sistema de coordenadas: si el CTM ya invierte Y para emular NSView.isFlipped, no invertir otra vez el índice de la fila. native-graph-pixel-reader-before.log conserva el fallo del harness; las 37 comprobaciones corregidas pasan y omitir dash conserva cuatro fallos de comportamiento.
- Consultar el estado de un toggle antes de pulsarlo en un test que exige activarlo. El minimapa viene visible por defecto; el primer test lo cerraba. No cambiar el producto para satisfacer esa suposición del test.
- Un timeout al habilitar automation mode es un fallo del runner antes de ejecutar tests. Conservar el xcresult, separar ese fallo de una regresión del producto y reintentar de forma acotada, sin modificar TCC ni contar pruebas no ejecutadas como aprobadas.

- Al compilar utilidades de geometría extraídas en un módulo headless, importar CoreGraphics explícitamente; Foundation por sí sola no garantiza los inicializadores de CGRect visibles en el target del compilador. minimap-allocation-baseline-checks.log conserva el error del harness; no es un fallo del algoritmo ni un control negativo válido.
- Verificar el mismo PID en primer plano antes y después de sintetizar arrastres; una captura que reactiva después la app no demuestra dónde se ejecutó el gesto. native-minimap-control-ui.log detectó Warp en primer plano al terminar un gesto; Canvas también falló, de modo que no se atribuye ese resultado al renderer nativo.

- Verificar nombres SF Symbols con NSImage(systemSymbolName:accessibilityDescription:), no por parecido con otro nombre. Los chevron.*.to.line producían botones vacíos/no alcanzables; arrow.*.to.line permite navegar a ambos extremos en minimap-valid-symbols-ui.xcresult. El inventario adicional encontró rocket.fill y git.branch inválidos. El inventario de literales no certifica nombres dinámicos ni acciones.
- Evitar nombres de módulo de frameworks para scripts Swift temporales: Symbols.swift colisiona con Symbols importado por SwiftUICore. Usar un nombre específico como GitMacSymbolInventory.swift; conservar el error como fallo del harness, no del producto.

No hay herramienta de memoria persistente disponible en esta sesión. Estas reglas quedan versionables dentro del proyecto y vinculadas a pruebas, sin modificar las instrucciones globales del usuario.

- Antes de construir un fixture de status, consultar FileStatusType: la categoría del array conflicted usa el caso unmerged. conflict-wip-production-tests.log conserva la compilación fallida; no cuenta como regresión del producto ni como prueba aprobada.
- Los scripts de verificación deben poder versionarse: comprobar git check-ignore además de ejecutar el archivo local. La regla *.py ocultaba los tres auditores de temas/símbolos; scripts/*.py queda exceptuado y audit-implementation rechaza archivos revisados que sigan ignorados. No se agregan al index automáticamente.
- En Swift, no ocultar un error de aislamiento cambiando el modo de concurrencia: construir el proveedor por defecto dentro de un inicializador aislado y mantener un inicializador explícito inyectable. terminal-demand-build.log conserva el rechazo del argumento por defecto; la corrección separa ambos inicializadores.
- Para comparar cwd físico en macOS, usar un oracle POSIX realpath y comparar el nombre exacto; URL.resolvingSymlinksInPath no normalizó /var a /private/var en este harness. terminal-path-diagnostic.log conserva los seis falsos fallos con exit 0 y rutas equivalentes; las mutaciones posteriores deben fallar por interpretación del shell, no por ese alias.
- Reducir estructuras de datos no demuestra reducir physical footprint. El experimento de tres pasadas fue equivalente en 130 casos, pero el Release llegó a 184878232 bytes de pico. Se conserva su fuente y medición, se retira del producto y no se declara optimización conseguida.
- No asumir que un panel persistente inicia cerrado: consultar el editor de terminal antes de buscar el botón del footer colapsado. terminal-literal-input-ui.xcresult se detuvo por esa suposición del test; conservar el fallo y seguir exigiendo input literal y bytes del proceso real.
- El color semántico secundario tampoco garantiza contraste sobre cualquier superficie de un preset: la primera corrección del caption pasó 8/9, Solarized Light quedó en 4.381. La corrección local usa texto primario; conflict-caption-primary-after.log pasa nueve sin alterar la paleta global.
- Antes de atribuir pérdida de teclas al editor, comparar un control nativo estándar y registrar modificadores en el fixture. terminal-native-control-ui.xcresult pierde c/apóstrofos en ambos campos y terminal-input-key-events.log registra Command (1048576) en esas teclas sintetizadas; teclado actual USInternational-PC. Se retiró el buffer experimental que no corregía el fallo. El helper de entrada usa typeKey con modificadores explícitos y conserva la aserción del texto exacto; no modifica el teclado del usuario.
- Al cambiar el resultado de un método de entrega, inspeccionar el método completo después del patch y probar su cuerpo real hasta la frontera de escritura. Un return true anterior al bucle de Ghostty compilaba con advertencia y vaciaba el editor sin enviar nada. terminal-wire-checks.log pasa ocho escenarios; terminal-wire-negative.log reproduce cinco fallos de comportamiento con ese retorno prematuro. Las pruebas del controlador de sugerencias no cubren la entrega nativa.
- Los controles históricos deben apuntar a una revisión inmutable, nunca al HEAD móvil del proyecto. scripts/regression-baseline.mjs fija 33bcb5739356ae133b8812159fde991700a56273; los workflows obtienen su historial. Después de un commit, repetir los controles negativos y exigir sus fallos de comportamiento, no solo exit 1 por falta de objeto o error de compilación.

- RelativeFormatStyle y RelativeDateTimeFormatter no tienen redondeo idéntico: ram-relative-date-tests.log reprodujo «hace 5 días» frente a «hace 4 días» y «dentro de 2 a» frente a «dentro de 1 a». Se conserva el formatter original compartido bajo NSLock, con locale/calendar autoupdating, en vez de relajar el test. ram-relative-date-preserved.log pasa 12 XCTest.
- Medir también la candidata de distribución y registrar geometría: el perfil privado de ventana baja no aprobó la ventana real más alta. El build 2 firmado alcanzó 158844056 bytes y el 3 152257664; no se publicaron ni instalaron. No reducir la ventana para hacer pasar el presupuesto.
